What is NGRX?
- NGRX is basically combination of RXJS and REDUX.
- RXJS we used in angular like observables
- Redux is basically global state management library taken from the react. All component can share this data among themselves.

What problem does NGRX solve?
- At a high-level, it mainly solves mainly the two main scenarios:
1. Sharing data between different components
2. A global state for the reuse of data
